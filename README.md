# shammybeats

Static beat store for **Prod. Shammy**. Content lives in `beats.json` and `mixing.json`. `node build.mjs` writes HTML into `dist/` for Netlify.

- Live (planned): https://shammybeats.netlify.app  
- Editor: `/admin/` (Decap CMS + Netlify Identity / Git Gateway)  
- Guide: [HOW-TO-ADD-A-BEAT.md](./HOW-TO-ADD-A-BEAT.md)
